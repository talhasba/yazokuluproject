# Provider Content Library

This folder contains editable views of the catalogue data in `data/programs.normalized.json`.

- `provider-contents.xlsx` is the detailed editing workbook. It has an index and separate `Info` and `Content` sheets for every provider. Program IDs are the stable keys for copying approved changes back to JSON.
- `provider-reference.docx` is the readable provider directory. It summarizes every provider and lists all programs with their short descriptions and key facts.

The files are generated snapshots. Editing them does not automatically update the website or JSON source.
